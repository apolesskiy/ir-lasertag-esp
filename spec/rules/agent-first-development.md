## Spec

Documentation is readable by humans and optimized for AI-agent consumption. No code in design documents — describe behavior and interfaces; reference implementation files by path instead of inlining code bodies.

README files in this repository target library consumers (humans and non-Speck agents). They are the user-facing contract and are preserved; spec documents describe the same system for development purposes and reference the READMEs and headers rather than duplicating them.
